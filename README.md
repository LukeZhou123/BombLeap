# Bomb Leap · 炸弹跳跃

> 穿过地下迷宫，找到石座上的宝剑。

一个像素风解谜平台游戏。**用炸弹炸墙、炸出隐藏机关、把自己炸上高台**，逐间解锁 30 间房，一路爬到塔顶拔剑。

- 引擎：Canvas 2D + ES Modules（纯前端，`web/` 目录直接开就能玩）
- 桌面壳：Tauri 2（macOS / Windows）
- 最新版本：`v1.0.1`

---

## 核心机制

### 炸弹是万能钥匙

- 最多同时持有 **2 颗炸弹**，先放先炸（普通难度起步 1 颗，捡到道具后变 2 颗）。
- **炸墙**：裂纹墙（地图上能看到的裂纹）炸过一次就永久打开；普通石头墙炸穿后还会重新长出来。
- **炸高台**：主角被爆炸冲击波弹起，跳到一次小跳够不到的高度。
- **炸隐藏拉杆**：有些拉杆埋在石头里（关卡里没有任何标记，小地图也不显示），必须先把墙炸碎、露出拉杆，再走过去按下。

### 机关

| 机关 | 说明 |
|---|---|
| **压力板** | 站上去才触发，离开就复位；同一石门的多块压力板必须同时压住。 |
| **拉杆** | 走过去自动拉下，**永久生效**；同组多根拉杆必须全部拉下才能解锁对应石门。 |
| **隐藏拉杆** | 埋在石墙 / 地面里，地图上不可见，小地图也不会提示。先用炸弹把埋着拉杆的那块石头炸掉，露出拉杆后走过去拉下。全图约 **44 根隐藏拉杆**，解谜时留意"炸完墙出现的新格子"。 |
| **石门** | 由压力板或同组拉杆开启，打开后保持开启。 |
| **裂纹墙** | 炸弹专用通道。 |

### 房间结构

- 共 **30 间房**（R0–R29），包含 **6 间密室** 和 **4 座爬塔**。
- 密室入口完全隐蔽，外观与普通石墙一样，**只有靠炸弹慢慢试**。
- 小地图只显示当前房间的轮廓，不会泄露密室位置，也不会标出隐藏拉杆。

### 操作

| 按键 | 动作 |
|---|---|
| `A` / `D` | 左右移动 |
| `空格` / `↑` | 小跳一格，刚好踩上炸弹 |
| `S` / `↓` | 放炸弹（放时会小跳一下） |
| `J` / `K` | 引爆最先放下的那颗（先放先炸） |
| `R` | 回到点亮的重生点 |
| `Esc` | 暂停 |

### 存档

- 标题页选 **开始游戏** 进入，**重新开始** 清空存档。
- 游戏中随时退出都会自动保存当前进度（房间、重生点、炸弹上限、计时、死亡数），下次打开直接 **继续**。

## 本地运行

### 只跑网页（最快）

```bash
cd bomb-leap
npm run web
# 然后浏览器打开 http://127.0.0.1:8123
```

### Tauri 桌面版

```bash
cd bomb-leap
npm install
npm run tauri dev        # 开发模式
npm run build            # 打包 macOS + Windows
```

## 代码结构

| 文件 | 职责 |
|---|---|
| `web/js/world.js` | 地图构建：房间、门、板、拉杆、裂纹墙、重生点、宝剑 |
| `web/js/game.js` | 游戏循环、物理（重力 / 跳跃 / 爆炸冲击波）、渲染、机关判定 |
| `web/js/main.js` | 标题页 / 暂停 / 通关界面、HUD、存档读写 |
| `web/js/constants.js` | 物理参数（重力、跳跃速度、爆炸半径等） |
| `web/js/audio.js` | 音效 |
| `src-tauri/` | Tauri 2 壳（Rust），窗口 + 文件系统权限 |

## 版本号同步

改动涉及版本时，以下四处要一起改：

- `package.json` → `version`
- `src-tauri/Cargo.toml` → `version`
- `src-tauri/Cargo.lock` → `version`
- `src-tauri/tauri.conf.json` → `version`

存档键会随版本号变动（如 `bombleap.world.v6`），避免旧存档加载新地图出错。
