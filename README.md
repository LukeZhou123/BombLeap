# Bomb Leap / 炸弹跳跃

像素风的炸弹解谜平台游戏：一张连续地图、8 座重生点，靠炸弹的冲击波飞上高台。

## 下载

到 [Releases](../../releases) 页面下载对应平台的安装包：

- macOS：`.dmg`（Apple Silicon / Intel 通用）
- Windows：`.msi` 或 `.exe`

安装后即可离线游玩，无需联网。

## 操作

| 按键 | 作用 |
| --- | --- |
| A / D 或 ← / → | 移动 |
| 空格 / W / ↑ | 小跳一格，刚好能踩上炸弹 |
| S / ↓ | 放炸弹（放的时候会小跳一下） |
| J | 引爆最先放下的炸弹 |
| K | 引爆最后放下的炸弹 |
| R | 回到最近点亮的重生点 |
| Esc | 暂停 |

## 玩法要点

- 场上最多同时放两块炸弹，第二块要先在地图里捡到发光的备用炸弹道具。
- 炸弹是实体方块，能踩上去，也能被爆炸掀飞；叠两颗可以爬得更高。
- 石门要靠压力板压住才开，压不住的板就放一颗炸弹在上面。
- 炸开的裂纹墙，离开房间后大约 8 秒会重新长回来。
- 点亮地图上全部 8 座重生点即通关。
